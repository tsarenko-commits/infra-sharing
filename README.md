# Backhaul SRLG: оптимизация совместного использования дорожной инфраструктуры

Репозиторий кода и артефактов к серии статей по отказоустойчивости дорожной ВОЛС
(shared risk link groups, MILP, Монте-Карло).

## Структура репозитория

```
.
├── README.md               этот файл
├── .gitignore              исключения git
├── specs/                  спецификации (источник истины)
│   ├── spec_core.txt           спецификация ядра MILP (полный экземпляр)
│   └── pilot_14_13_5_spec.txt  спецификация пилотного экземпляра 14/13/5
├── src/                    код ядра
│   └── (генератор экземпляра, сведённая MILP, solve_core.py)
├── tests/                  тесты на контрольные числа
├── scripts/                утилиты (bench_recalc и др.)
├── results/                результаты прогонов (не коммитятся большие файлы — см. .gitignore)
└── archive/                архивные снимки (не коммитятся — см. .gitignore)
```

## Окружение

- Python 3.11+
- HiGHS (решатель MILP) — через `pip install highspy` либо PuLP + CBC как резерв
- Зависимости фиксируются в `requirements.txt` (будет добавлен вместе с кодом ядра)

## Процедура резервного копирования (обязательный раздел — решение от 2026-11-02)

1. GitHub — основная площадка: CI-прогоны на публичном репозитории (безлимитные минуты).
2. Локальная копия — `git clone` один раз, затем `git pull` после каждого сеанса работы.
3. Bundle-снимок — после каждой значимой вехи или раз в неделю:
   `git bundle create infra-ci_backup_<дата>.bundle --all`
   Снимок хранить на Яндекс.Диске и/или флешке (вне репозитория).
4. Зеркало GitVerse — активный резерв: push в два remote либо Actions-джоб
   с `git push --mirror`.

Восстановление из снимка: `git clone backup_full.bundle восстановленная_папка`.

ZIP со страницы GitHub бэкапом не считается: он не содержит истории коммитов.

## Порядок коммитов (план)

1. Каркас: README.md, .gitignore, specs/ (этот коммит)
2. Ядро: генератор экземпляра + сведённая MILP + solve_core.py
3. Тесты на контрольные числа (1422,5 / 419,2 / 443,77 / 105,86 %; целевая 3 664 625 550)
4. ci.yml — GitHub Actions: тесты на каждый push
5. Монте-Карло: bench_recalc v14 (канон), README раздел «Воспроизводимость»

## Воспроизводимость

Фиксируются: версии Python/NumPy/SciPy/HiGHS (pip freeze -> requirements.txt),
seed для Монте-Карло, дескриптор версии в specs/. Канон МК: 0,004 отказа/км · 0,4/100 км/год, РД 45.047-99, MTTR U(4;48), 6 млн модельных лет (суммарно по всем прогонам; один модельный год = один смоделированный год жизни сети).
